# 课表页无固定时间课程显示功能

## 功能概述

在课表页面底部以卡片列表形式显示没有固定上课时间的课程。

## 实现细节

### 数据处理

1. **课程分类**：在 `convertCourseInfoToCourse` 函数中，将课程分为两类：
   - `scheduledCourses`：有固定时间的课程，显示在课表网格中
   - `unscheduledCourses`：无固定时间的课程，显示在底部列表中

2. **判断逻辑**：通过检查 `courseInfo.time` 是否为空来区分课程类型
   ```typescript
   if (!courseInfo.time || courseInfo.time.length === 0) {
     // 无时间课程处理
   } else {
     // 有时间课程处理
   }
   ```

### 状态管理

- 新增 `unscheduledCourses` 状态用于存储无固定时间的课程
- 在 `fetchCourseTable` 函数中分别收集有时间和无时间课程

### UI 展示

1. **布局**：无固定时间课程显示在课表下方，使用网格布局
2. **样式**：
   - 响应式网格：`gridTemplateColumns: 'repeat(auto-fill, minmax(300px, 1fr))'`
   - 根据课程状态（已选/预选/候补）使用不同颜色
   - 卡片阴影和圆角设计

3. **信息展示**：
   - 课程名称（加粗显示）
   - 教师姓名
   - 上课地点
   - 状态标签（已选/预选/候补）
   - 时间显示为"待定"

### 状态标识

- **已选课程**：绿色背景，"已选"标签
- **预选课程**：蓝色背景，"预选"标签  
- **候补课程**：橙色背景，"候补"标签（显示排队位置）
- **默认课程**：粉色背景（教师查看自己开设的课程）

## 支持的用户角色

- **学生**：查看自己的已选/预选/候补课程中的无时间课程
- **教师**：查看自己开设的课程中的无时间课程

## 文件修改

主要修改文件：`src/Pages/CourseTablePage.tsx`

### 核心函数

1. `convertCourseInfoToCourse()` - 课程数据转换和分类
2. `fetchCourseTable()` - 获取并分离有时间/无时间课程
3. `renderUnscheduledCourses()` - 渲染无时间课程列表

## 效果预览

- 课表网格正常显示有固定时间的课程
- 底部标题"无固定时间课程"
- 网格卡片展示，每张卡片包含完整课程信息
- 不同状态课程有视觉区分

## 兼容性

- 向后兼容：如果没有无时间课程，底部列表不显示
- 错误处理：API 调用失败时有相应提示
- 数据容错：处理课程信息不完整的情况
